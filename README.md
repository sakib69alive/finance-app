# হিসাবী: অফলাইন ব্যবসার হিসাব

মূলধন, খরচ, প্রতি ইউনিটের আসল খরচ, টার্গেট অনুযায়ী বিক্রি দাম আর লাভ-ক্ষতি, সব এক জায়গায়।
Android আর iPhone দুটোতেই চলে। সব ডেটা ফোনেই থাকে, কোনো সার্ভার নেই।

## কম্পিউটারে চালিয়ে দেখা

```bash
node tools/serve.js
```

তারপর ব্রাউজারে http://localhost:5173 খুলুন।

## ফোনে ইনস্টল

ফোনে অফলাইন অ্যাপ হিসেবে ইনস্টল করতে ফাইলগুলো একবার কোনো **HTTPS** সাইটে রাখতে হবে। ফ্রি অপশন: GitHub Pages।

1. GitHub-এ একটা নতুন repo খুলে এই ফোল্ডারের সব ফাইল আপলোড করুন।
2. Settings → Pages → Branch: `main` → Save। কিছুক্ষণ পর একটা লিংক পাবেন।
3. ফোনে লিংকটা খুলুন:
   - **Android (Chrome):** ⋮ মেনু → "Install app" / "Add to Home screen"
   - **iPhone (Safari):** Share বাটন → "Add to Home Screen"
4. একবার ইনস্টলের পর ইন্টারনেট ছাড়াই চলবে।

## আপডেট দিলে

কোড বদলালে `sw.js`-এর `VERSION` বাড়ান (যেমন `hisabi-v2`)। ফোনে অ্যাপ দুইবার খুললে নতুন ভার্সন চলে আসবে। ডেটা মুছবে না।

## ফাইল

| ফাইল | কাজ |
|---|---|
| `index.html` | অ্যাপের কাঠামো |
| `app.js` | হিসাবের ইঞ্জিন, সব স্ক্রিন, ব্যাকআপ |
| `styles.css` | ডিজাইন (লাইট/ডার্ক থিম) |
| `sw.js` | অফলাইনে চালানোর জন্য |
| `manifest.webmanifest`, `icons/` | ফোনে ইনস্টল হওয়ার জন্য |
| `tools/` | আইকন বানানো আর লোকাল সার্ভার (শুধু ডেভেলপমেন্টে লাগে) |
